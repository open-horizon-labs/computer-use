# Native completion experiment preflight and dissent

Scope: experiment-only current Cua SDK host and owned native AppKit fixtures. Test serial, separately owned supervision, application transaction evidence, combined and current Reference. All inputs use current exact window/element bindings. No production driver replacement, permission edits, VM, GPU or user document input. User explicitly authorizes host desktop use; competing inputs/focus interference invalidate timing and safety, not silently pass.

Dissent: a pending receipt alone cannot bypass the same-pid mutation lock; loosening that lock before dispatch/restoration/read-back would interleave input. The experiment releases it only after those phases and keeps the original action task's full observation snapshot alive. That remains unqualified for ordinary dependent actions: only explicit independent field plans are eligible; any changed record/context or rejected action stops before further input. Application evidence exists only because this app provides immutable transaction ID/outcome acknowledgements. Generic AX echo is not accepted. Callback delivery was absent in the earlier blocked-main-thread SDK host; this host installs the observer and pumps the main CFRunLoop. Native foreground proof is required, not inferred from the event loop. Missing/misbound acknowledgement, late rejection, partial failure, record changes and request cancellation must refuse or fence, never replay. Disconnect drains existing input tasks before shutting down.

Decision: proceed with reversible private experiment, not public API or production policy change. Hold an advisory exclusive local study lock, inspect conflicting processes, keep candidates latest and versions/hash/source receipts. Stop live trials on focus interference, manual input, changed upstream source, unverified acknowledgements, or uncertain mutation. Do not terminate other agents/processes. Real fixtures quantify feasibility; RFC/dissent remains necessary before shipping receipt or completion contracts.
